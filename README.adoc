= fluent-tooling

____
Tree-sitter grammar, linter, and editor tooling for the https://projectfluent.org/[Fluent localization system] from Mozilla.
____

image:https://img.shields.io/badge/doc-outskirtslabs-orange.svg[doc,link=https://docs.outskirtslabs.com/fluent-tooling/next/]
image:https://img.shields.io/badge/status-experimental-red.svg[status: experimental,link=https://docs.outskirtslabs.com/open-source-vital-signs#experimental]
image:https://ci.outskirtslabs.com/repos/github/outskirtslabs/fluent-tooling/badge.svg[alt=nixbot,link=https://ci.outskirtslabs.com/repos/github/outskirtslabs/fluent-tooling]

This repository contains:

* https://docs.outskirtslabs.com/fluent-tooling/next/ftl-lint[`ftl-lint`], a command-line linter with compiler-style diagnostics;
* https://docs.outskirtslabs.com/fluent-tooling/next/tree-sitter[`tree-sitter-fluent`], an error-tolerant Tree-sitter grammar with Rust bindings; and
* https://docs.outskirtslabs.com/fluent-tooling/next/emacs[`fluent-ts-mode`], a native Tree-sitter major mode for Emacs.

Project status: *https://docs.outskirtslabs.com/open-source-vital-signs#experimental[Experimental]*.

== Quick start

Run the linter from this checkout:

[source,bash]
----
nix run . -- path/to/messages.ftl
----

See the https://docs.outskirtslabs.com/fluent-tooling/next/ftl-lint[`ftl-lint` guide] for installation, command-line options, diagnostic codes, and editor integration.

== Nix packages

The flake exports two named packages and selects `ftl-lint` by default:

[cols="2,2",options="header"]
|===
|Command |Package

|`nix build` or `nix build .#ftl-lint`
|The `ftl-lint` executable

|`nix build .#tree-sitter-fluent`
|The compiled Tree-sitter grammar
|===

See the https://docs.outskirtslabs.com/fluent-tooling/next/tree-sitter[`tree-sitter-fluent` guide] for the grammar package's layout and integration options.

== Development

Enter the reproducible development shell and run the complete quality gate:

[source,bash]
----
nix develop
bb ci
----

The https://docs.outskirtslabs.com/fluent-tooling/next/development[development guide] covers repository structure, parser generation, individual checks, and fixture provenance.
